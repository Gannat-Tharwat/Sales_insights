# Sales Insights

## Project Description

Store Sales Dataset Analysis using Power BI.

The project focuses on data cleaning and preprocessing, identifying key analysis questions, analyzing sales performance across products and regions, and creating an interactive Power BI dashboard to present insights and support business decisions.
